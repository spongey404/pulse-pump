Decisions — each numbered against 8a
STRUCTURE
Flat — no card, no rounded container, no elevated surface inside the screen. Content sits on --surface-canvas and every division is a 1px --rule-hair rule running the full width inside 16px padding. The composer's share card (7a) IS a card because it is a shareable artifact; this is a reading surface. The exercise list is a four-column table, not stacked blocks: 1fr 30px 68px 70px, gap 6 — the name column must clear the longest name (OVERHEAD TRICEP EXT) on one line.
1
Header — pinned, does not scroll
Overline JAY · SAT 2 MAY Space Mono 400 8px / 1.5px tracking / muted. Title PUSH DAY Archivo 900 24px / 0.5px / line-height 1. CLOSE ✕ right. Whose session and when — never just "SESSION".
2
Ticker — full bleed, edge to edge
The design-system TickerStrip: no side padding, no radius, no container. This session's headlines only — BENCH ▲ PR +5KG · OHP ▲ PR +2KG · VOL ▲ 8.4%. Marquee 40px/sec linear.
3
Stats — silhouette left, 2×2 right
BodyHeat at exactly 66×106 with flex:none — it has no intrinsic width and will eat the row if left to auto. Beside it a 2-column grid, gap 18px 10px, reading SETS · VOLUME then IMPROVED · PRS. Values Archivo 900 26px. SETS and VOLUME are KPIBlock compact; IMPROVED and PRS are hand-built twins because the value needs colour — green numerator with a muted /9, and gold + glow for PRs. Row gap 18px is what keeps this legible; do not compress it.
4
Table — every exercise, in the order performed
Nothing truncated, nothing sorted. All 9 exercises as logged — a session record, not a highlight reel. No "+2 more".

Header strip: EXERCISE left, SET BEST VS LAST right-aligned, Space Mono 400 8px / 1.5px muted, hairline below.
Row 1 of each exercise: name Archivo 700 14px uppercase, 0.2px tracking, never wrapping — gold if PR, ink if improved, muted if neither. PR mark beside it, Space Mono 700 8px gold + glow. Set count Space Mono 400 13px muted. Best set Space Mono 700 14px, gold on PR rows. Delta Space Mono 700 11px — ▲ +5KG green, or — muted.
Row 2: the set list inline, · separated in --text-ghost, 7px above.
4
↳ Set list — the new part
Every set is typed by what it was, so the shape of the session is readable without doing arithmetic. Three states, all Space Mono 12px:
105×3Best set on a PR exercise — 700, gold, glow
18×12Best set otherwise — 700, --text-primary
60×8Every other set — 400, --text-muted
Exactly one set per exercise takes the emphasis — the one matching that exercise's BEST value. Warm-ups and back-off sets recede. The separators stay --text-ghost so they never compete with the numbers.
5
Reactions — at the end, never docked
Heart + count and comment + count, after the list and above the watermark. 24px glyphs at stroke 1.6, counts Space Mono 700 14px ink, 44px-min targets, gap 22, no borders or pills. Deliberately not a docked bar: that would cost 56px of table on every scroll to serve an occasional tap. Then the watermark — 7×7 accent square, radius 2, plus PULSE / PUMP.
DATA
Every total is derived from the exercise list, never stored beside it — sets, volume, improved count, PR count. The feed post header, this header and the feed's collapsed row read the same derived values, so they cannot drift.

Per-muscle set counts need real data. The body map is only worth showing if chest reads 12 and triceps 7. An even split across worked muscles makes it decorative. Needs a primary/secondary muscle tag per exercise, secondary counting fractionally.
